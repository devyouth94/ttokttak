# Expo 기반 iOS 홈 화면 위젯

## 맥락

읽기 전용 iOS 홈 화면 위젯을 제공하면서 재생성 가능한 Expo 설정 경계를 유지한다.
일정 제목을 표시하려면 앱과 위젯 확장이 복호화된 표시 데이터를 공유해야 한다.

## 결정

공식 `expo-widgets`와 `app.config.ts` config plugin으로 위젯 확장을 생성한다.
앱이 기존 occurrence 규칙으로 위젯 타임라인을 계산하고 App Group `UserDefaults`에 일정 색상, 제목, 알림 시각과 지난 날짜 수만 저장한다.
일정 설명은 저장하지 않고 로그아웃과 계정 삭제 때 로그인 안내 상태로 덮어쓴다.

## 결과

- 생성된 `ios/` 코드를 직접 수정하지 않는다.
- 복호화된 일정 제목이 앱과 위젯만 접근 가능한 로컬 공유 저장소에 남는다.
- 다른 기기의 변경은 앱 실행이나 foreground 복귀 뒤에 반영된다.
- alpha 라이브러리의 변경과 네이티브 재빌드 비용을 감수한다.
- 저장 상태 암호화나 지원하지 않는 WidgetKit 기능이 필요해질 때 Swift 기반 확장을 다시 검토한다.
