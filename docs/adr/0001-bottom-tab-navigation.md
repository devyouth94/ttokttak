# 하단 탭과 집중 화면

## 맥락

홈, 목록, 캘린더와 설정은 동등한 주요 목적지다.
일정 상세, 생성과 수정은 특정 작업에 집중해야 하며 탭 목적지처럼 보이면 안 된다.

## 결정

- 네 주요 화면을 하단 탭 루트로 둔다.
- iOS는 시스템 네이티브 탭을 사용하고 Android는 커스텀 탭을 유지한다.
- iOS 26의 탭은 시스템 Liquid Glass를 그대로 사용하며 스크롤할 때 축소하지 않는다.
- iOS 탭 아이콘은 SF Symbols를 사용한다.
- 일정 추가는 탭이 아닌 전역 동작으로 둔다.
- iOS에서는 일정 추가를 탭 위 우하단의 네이티브 원형 버튼으로 제공한다.
- Android에서는 일정 추가를 기존 탭 위 가운데 버튼으로 제공한다.
- 상세, 생성과 수정에서는 하단 탭을 숨긴다.
- 이미 선택된 탭을 다시 누르면 추가 navigation을 하지 않는다.

## 결과

주요 영역 전환과 일정 관리 흐름이 분리된다.
활성 탭 재선택으로 root reset이나 scroll-to-top을 제공하지 않는다.

## 검토한 대안

- 모든 화면에 탭 노출: 집중 화면이 탭 목적지처럼 보여 제외했다.
- 생성을 별도 탭으로 배치: 생성은 지속되는 영역이 아니라 동작이므로 제외했다.
