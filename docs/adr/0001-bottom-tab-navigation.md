# Bottom Tab Navigation

하단 탭은 홈, 목록, 캘린더, 설정의 **탭 루트**를 오가는 주요 영역 전환 장치로 사용한다. 다른 탭으로 전환해도 각 탭의 현재 화면 상태는 보존하고, 같은 탭을 다시 누르면 해당 탭의 **탭 루트**로 돌아간다. 알림함, 상세, 생성, 수정 같은 **집중 화면**에서는 하단 탭을 숨겨 작업 맥락을 유지한다.

이 결정은 iOS 탭 관례와 작업형 앱의 예측 가능성 사이의 절충이다. 탭별 stack은 보존해 영역 상태를 잃지 않게 하되, 하단 탭은 **탭 루트**에서만 노출해 집중 화면이 탭 목적지처럼 보이지 않게 한다. 가운데 `+` 버튼은 탭이 아니라 전역 생성 액션으로 유지한다.
