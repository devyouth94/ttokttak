# 구버전과 호환되는 일정 색상 저장

사용자 지정 일정 색상은 정확한 RGB 값이 필요하지만 배포된 구버전 앱은 7개 `color_key`만 처리할 수 있다. 새 앱의 기준값은 `color_hex`에 저장하고, 구버전 표시용으로 가장 가까운 프리셋 `color_key`를 함께 저장한다.

## 결과

- 기존 일정의 `color_hex`는 현재 프리셋 색상으로 채운다.
- 구버전이 같은 `color_key`로 일정을 수정하면 사용자 지정 `color_hex`를 보존한다.
- 구버전이 다른 프리셋을 고르면 `color_hex`도 해당 프리셋으로 바꾼다.
- 구버전 사용을 종료할 수 있다고 확인한 뒤 별도 migration에서 `color_key`를 제거한다.
