# 일정 인덱스 구현 계획

## 요약

전역 히스토리 탭을 제거하고 같은 위치에 `일정` 탭을 추가한다.
`일정` 탭은 사용자가 설정한 반복 일정 항목을 한 페이지에서 보는 인덱스 화면이다.
기존 캘린더 탭과 항목 상세의 최근 히스토리는 유지한다.

## 범위

- 하단 탭은 `홈`, `캘린더`, `일정`, `설정`으로 구성한다.
- 기존 `히스토리` 탭, 라우트, 전역 화면 코드는 삭제한다.
- 전역 히스토리 전용 무한 스크롤 쿼리는 삭제한다.
- 상세 화면의 최근 히스토리 기능은 유지한다.
- 상세 화면에서 재사용 중인 히스토리 컴포넌트와 타입은 유지한다.
- 필터는 이번 범위에서 제외한다.

## 화면 요구사항

### 기본 구성

- 화면 제목은 `일정`을 사용한다.
- 반복 일정 추가 진입점을 제공한다.
- 일정이 없으면 화면 중앙에 일정 추가를 유도하는 문구를 보여준다.
- 빈 상태에서도 반복 일정 추가 화면으로 이동할 수 있어야 한다.

### 배치 기준

- 기존 `AppScreen`과 `ScreenHeader` 흐름을 따른다.
- 헤더에는 제목 `일정`을 보여준다.
- 반복 일정 추가 버튼은 헤더 오른쪽에 둔다.
- 정렬 선택 UI는 헤더 아래, 목록 위에 둔다.
- 정렬 선택 UI는 작고 단순한 컨트롤로 만든다.
- 목록은 세로 카드 리스트로 구성한다.
- 카드 간격과 좌우 여백은 홈, 캘린더 화면의 카드 밀도에 맞춘다.
- 하단 탭은 `홈`, `캘린더`, `일정`, `설정` 순서를 유지한다.
- `일정` 탭이 선택된 상태에서는 하단 탭의 `일정` 아이콘만 활성 상태로 보인다.

### 목록 카드

- 카드에는 아래 정보만 기본 표시한다.
  - 제목
  - 반복 규칙 요약
  - 다음 예정일 값
- 다음 예정일 값에는 `다음 일정` 같은 라벨을 붙이지 않는다.
- 예시는 `오늘 오전 9:00`, `5월 12일 오전 8:00`처럼 날짜/시간만 보여준다.
- 카드 오른쪽에는 상세 이동을 암시하는 작은 chevron을 둘 수 있다.
- 카드에 수정, 삭제 버튼을 직접 노출하지 않는다.
- 카드를 누르면 기존 항목 상세 화면으로 이동한다.
- 수정과 삭제는 상세 화면의 기존 관리 메뉴를 사용한다.

### 정렬

- 기본 정렬은 최근 생성순이다.
- 정렬 선택지는 아래 3개만 제공한다.
  - 최근 생성순
  - 제목순
  - 다음 예정일 빠른순
- 정렬 선택 UI는 목록 상단에 둔다.
- 정렬 변경은 화면 안에서 즉시 반영한다.

## 작업 체크포인트

### 1. 라우팅과 탭 구조

- [x] `히스토리` 탭을 하단 내비게이션에서 제거한다.
- [x] `일정` 탭을 하단 내비게이션에 추가한다.
- [x] 기존 `캘린더` 탭과 라우트는 유지한다.
- [x] 전역 히스토리 라우트를 삭제한다.
- [x] 탭 루트 판정에 `일정` 라우트를 반영한다.

### 2. 일정 인덱스 화면

- [ ] 반복 일정 목록을 조회한다.
- [ ] 제목, 반복 규칙 요약, 다음 예정일 값을 카드에 표시한다.
- [ ] 다음 예정일 값 앞에 `다음 일정` 라벨을 붙이지 않는다.
- [ ] 카드 선택 시 항목 상세 화면으로 이동한다.
- [ ] 반복 일정 추가 진입점을 연결한다.
- [ ] 빈 상태 문구와 추가 진입점을 구현한다.

### 3. 정렬

- [ ] 최근 생성순을 기본값으로 적용한다.
- [ ] 제목순 정렬을 구현한다.
- [ ] 다음 예정일 빠른순 정렬을 구현한다.
- [ ] 다음 예정일이 없는 항목의 정렬 위치를 일관되게 처리한다.

### 4. 히스토리 정리

- [ ] 전역 `HistoryScreen`을 삭제한다.
- [ ] 전역 히스토리 라우트 파일을 삭제한다.
- [ ] 전역 히스토리 전용 쿼리와 헬퍼를 삭제한다.
- [ ] 상세 화면의 최근 히스토리에 필요한 컴포넌트는 유지한다.
- [ ] 남은 import와 query key 참조를 정리한다.

## 완료 기준

- [ ] 하단 탭에서 `히스토리`가 보이지 않는다.
- [ ] 하단 탭에서 `홈`, `캘린더`, `일정`, `설정`이 보인다.
- [ ] `캘린더` 화면은 기존처럼 동작한다.
- [ ] `일정` 화면에서 등록된 반복 일정 항목을 볼 수 있다.
- [ ] 일정 카드에는 제목, 반복 규칙 요약, 다음 예정일 값이 보인다.
- [ ] 일정 카드에는 `다음 일정` 라벨이 보이지 않는다.
- [ ] 일정 카드를 누르면 상세 화면으로 이동한다.
- [ ] 일정 카드에는 수정, 삭제 버튼이 직접 보이지 않는다.
- [ ] 빈 상태에서 일정 추가 행동이 가능하다.
- [ ] 상세 화면의 최근 히스토리는 기존처럼 보인다.
- [ ] 전역 히스토리 전용 코드는 남아 있지 않다.

## 검증 시나리오

### 시나리오 A: 기본 탭 이동

1. 앱을 실행한다.
2. 하단 탭을 확인한다.
3. `캘린더` 탭에 진입한다.
4. `일정` 탭에 진입한다.

기대 결과:

- `히스토리` 탭은 보이지 않는다.
- `캘린더` 탭은 기존 화면을 보여준다.
- `일정` 탭은 반복 일정 목록을 보여준다.

### 시나리오 B: 일정 상세 이동

1. `일정` 탭에 진입한다.
2. 반복 일정 카드를 누른다.

기대 결과:

- 해당 항목 상세 화면으로 이동한다.
- 상세 화면의 수정, 삭제 메뉴를 사용할 수 있다.
- 상세 화면의 최근 히스토리가 유지된다.

### 시나리오 C: 정렬 변경

1. `일정` 탭에 진입한다.
2. 정렬을 `제목순`으로 바꾼다.
3. 정렬을 `다음 예정일 빠른순`으로 바꾼다.

기대 결과:

- 목록 순서가 선택한 정렬 기준에 맞게 바뀐다.
- 필터 UI는 보이지 않는다.

### 시나리오 D: 빈 상태

1. 등록된 반복 일정이 없는 계정으로 진입한다.
2. `일정` 탭을 연다.

기대 결과:

- 화면 중앙에 일정 추가를 유도하는 문구가 보인다.
- 반복 일정 추가 화면으로 이동할 수 있다.
