# Triage Labels

스킬은 다섯 가지 triage 역할을 사용한다.

이 파일은 각 역할을 실제 GitHub 라벨 이름에 매핑한다.

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 관리자가 이슈를 평가해야 함 |
| `needs-info` | `needs-info` | 제보자에게 추가 정보가 필요함 |
| `ready-for-agent` | `ready-for-agent` | 에이전트가 바로 작업할 수 있음 |
| `ready-for-human` | `ready-for-human` | 사람이 직접 구현하거나 판단해야 함 |
| `wontfix` | `wontfix` | 처리하지 않기로 함 |

스킬이 triage 역할을 언급하면 이 표의 GitHub 라벨을 사용한다.

라벨 체계를 바꾸면 오른쪽 `GitHub label` 값을 먼저 수정한다.
