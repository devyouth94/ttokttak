# Product Spec

이 문서는 현재 앱에서 사용자에게 제공하는 제품 범위만 정의한다.
반복 계산 규칙은 `DOMAIN_LOGIC.md`, 구현 구조는 `SYSTEM_DESIGN.md`를 따른다.

## Product

**Ttokttak**은 반복되는 생활 항목을 일정으로 등록하고, 알림을 받고, 완료 또는 건너뛰기 기록을 남기는 개인 리마인더 앱이다.

핵심 대상은 매일 반복되는 루틴만이 아니다.
복용, 교체, 정비, 학습처럼 주기가 있는 생활 항목을 같은 방식으로 관리한다.

## Launch Scope

첫 스토어 출시는 대한민국과 한국어 사용자를 기본 기준으로 한다.
표시 언어, 공개 문서, 스토어 메타데이터 원문은 한국어와 English를 제공한다.
이용약관, 개인정보처리방침, 계정 삭제 요청, 지원 문서는 기존 공개 URL 안에서 한국어와 English를 함께 제공한다.

## Terms

- **일정**: 사용자가 관리하는 반복 생활 항목.
- **반복 규칙**: 일정이 언제 다시 발생하는지 정하는 규칙.
- **occurrence**: 반복 규칙으로 계산된 개별 예정 시점.
- **완료**: occurrence를 실제로 실행했음을 남기는 처리.
- **건너뛰기**: occurrence를 이번에는 실행하지 않기로 남기는 처리.
- **지난 일정**: 예정 날짜가 지났지만 완료 또는 건너뛰기 처리되지 않은 occurrence.
- **일정 색상**: 같은 일정을 여러 화면에서 구분하기 위한 7색 표시 색상.
- **종료일**: 일정이 occurrence를 만드는 마지막 날짜.
- **기기 로컬 알림**: 서버 발송 없이 현재 기기 OS에 예약하는 알림.
- **계정 삭제**: 사용자가 Ttokttak 계정과 연결된 사용자 데이터를 지워 달라고 시작하는 처리.
- **계정 삭제 요청**: 앱에 로그인할 수 없는 사용자가 공개 웹 경로에서 Ttokttak 계정 삭제를 요청하는 접수.

사용자-facing 화면에서는 관리 대상을 기본적으로 **일정**이라고 부른다.
`알림`은 notification 의미에만 사용한다.

## Current Scope

현재 앱은 다음 기능을 제공한다.

- Supabase Auth 기반 로그인.
- Apple / Google 로그인 진입점.
- 일정 생성, 수정, 삭제.
- 반복 규칙 설정.
- 알림 시간과 알림 켜기/끄기 설정.
- 일정 색상 선택.
- 선택 종료일 설정.
- 고정형 또는 완료일 기준 계산 선택.
- 홈에서 오늘, 다가오는 일정, 지난 일정 확인.
- 홈에서 완료 또는 건너뛰기 처리.
- 일정 목록 조회와 정렬.
- 일정 상세 조회, 최근 처리 기록 5건 확인, 수정/삭제 진입.
- 달력 월간 조회와 선택 날짜 일정 목록 확인.
- 설정에서 알림 권한, 시간대, 계정, 표시 이름, 이용약관 링크, 개인정보처리방침 링크, 로그아웃, 계정 삭제 확인.

현재 제공하지 않는 범위는 다음과 같다.

- 위젯.
- 알림함.
- 원격 푸시 발송은 추후 필요 시 별도 작업으로 다룬다.
- snooze.
- 반복 재알림.
- 통계 화면.
- 협업 또는 공유.
- 완전한 오프라인 충돌 해결 UX.

## Supported Recurrence

지원하는 반복 규칙은 다음과 같다.

- 한 번.
- 매일.
- n일마다.
- 매주.
- n주마다.
- 매달.
- n달마다.

완료일 기준 계산은 `daily`, `interval_days`, `monthly`, `interval_months`에서만 제공한다.
한 번 일정과 주간 계열은 고정형만 제공한다.

## Screens

### Login

- Apple / Google 로그인을 제공한다.
- 로그인 버튼 아래에 이용약관과 개인정보처리방침 동의 문구를 표시한다.
- 로그인 화면에서 공개 웹 이용약관으로 이동할 수 있다.
- 로그인 화면에서 공개 웹 개인정보처리방침으로 이동할 수 있다.
- 세션이 복원되면 홈으로 이동한다.

### Home

- 홈은 일정 처리의 중심 화면이다.
- 날짜 선택은 오늘부터 15일 범위를 제공한다.
- 선택 날짜가 오늘이면 지난 일정, 오늘, 다가오는 일정 섹션을 보여준다.
- 다가오는 일정은 앞으로 14일 범위만 보여준다.
- 선택 날짜가 오늘이 아니면 해당 날짜의 예정 일정만 보여준다.
- 완료와 건너뛰기는 홈에서만 제공한다.
- 지난 일정을 처리하면 그 이전 미해결 지난 일정도 함께 같은 액션으로 처리한다.

### Schedule List

- 등록된 활성 일정을 목록으로 보여준다.
- 기본 정렬은 제목순이다.
- 생성순 정렬도 제공한다.
- 각 row는 제목, 반복 규칙 요약, 다음 예정 시간 또는 `예정 없음`을 보여준다.
- row를 누르면 상세 화면으로 이동한다.

### Item Detail

- 일정의 대표 상태, 다음 일정 또는 지난 일정, 설정 요약, 최근 처리 기록 5건을 보여준다.
- 최근 처리 기록은 실제 처리일을 보여주고 occurrence 예정일이 다르면 예정일을 함께 보여준다.
- 상세 화면에서는 완료와 건너뛰기를 제공하지 않는다.
- 수정과 삭제는 상세 화면에서 진입한다.
- 일정 내용을 복구할 수 없으면 복구 실패 안내와 삭제 동작을 제공한다.

### Add / Edit Item

- 제목은 필수다.
- 설명은 선택이다.
- 시작일, 알림 시간, 반복 규칙, 일정 색상, 알림 켜기/끄기를 설정한다.
- 반복 일정은 종료일을 선택적으로 설정한다.
- 새 일정의 기본 색상은 빨강이다.
- 수정 모드에서는 시작일을 바꾸지 않는다.
- 수정 모드에서는 종료일을 추가, 변경, 제거할 수 있다.
- 한 번 일정에서는 종료일을 제공하지 않는다.
- 종료일은 시작일과 알림 시간 영역에서 설정한다.
- 종료일 switch를 끄면 종료일 값을 제거한다.
- 종료일 switch가 켜지면 종료일 라벨 아래에 중복 라벨 없이 날짜 선택 값을 표시한다.
- 규칙에 영향을 주는 수정은 이후 occurrence에만 적용된다.

### Calendar

- 월간 달력을 보여준다.
- 월 이동은 달력 상단 화살표로만 제공한다.
- 월을 이동하면 이동한 달의 1일을 선택한다.
- 날짜 셀에는 occurrence 상태가 아니라 일정 색상 marker를 표시한다.
- 선택 날짜 목록에는 시간, 상태, 제목을 보여준다.
- 달력은 확인용 화면이며 occurrence 처리는 제공하지 않는다.

### Settings

- 알림 권한 상태를 보여주고 시스템 설정으로 이동할 수 있다.
- 표시 언어를 한국어 또는 English로 선택할 수 있다.
- 테마를 시스템, 라이트, 다크 중 하나로 선택할 수 있다.
- 테마 기본값은 시스템이다.
- 테마는 로그인, 홈, 목록, 캘린더, 상세, 생성, 수정, 설정 화면에 적용한다.
- 현재 시간대를 보여준다.
- 앱 표시 이름을 수정할 수 있다.
- 공개 웹 이용약관으로 이동할 수 있다.
- 공개 웹 개인정보처리방침으로 이동할 수 있다.
- 계정 삭제를 시작할 수 있다.
- 계정 정보와 계정 관리는 분리한다.
- 계정 정보 카드에는 이름과 이메일을 표시한다.
- 환경 카드에는 표시 언어, 테마, 시간대 순서로 표시한다.
- 계정 관리 카드에는 로그아웃과 계정 삭제를 표시한다.
- 계정 삭제는 별도 화면이 아니라 설정 화면의 확인 모달로 처리한다.
- 계정 삭제 확인 모달은 삭제 대상과 되돌릴 수 없음을 안내한다.
- 계정 삭제 확인 모달 제목은 `계정 삭제`로 표시한다.
- 계정 삭제 확인 모달 본문은 `계정과 저장된 일정이 모두 삭제됩니다. 이 작업은 되돌릴 수 없습니다.`로 표시한다.
- 계정 삭제 확인 모달 버튼은 `취소`와 `계정 삭제`로 표시한다.
- 계정 삭제 실패는 기본적으로 단순 실패 안내로 표시한다.
- 로그인 세션이 없거나 만료된 경우에는 다시 로그인한 뒤 시도하라는 안내를 표시한다.
- 로그아웃을 제공한다.

## Product Policies

### Missed Items

- 완료 또는 건너뛰기 하지 않은 occurrence는 자동으로 다음날로 밀리지 않는다.
- 날짜가 지나면 지난 일정으로 남는다.

### Schedule Deletion

- 사용자는 상세 화면에서 일정을 삭제할 수 있다.
- 삭제된 일정은 활성 목록, 홈, 캘린더, 기기 로컬 알림 후보에서 제외한다.
- 삭제는 계정 삭제와 다른 일정 단위 관리 동작이다.

### Notifications

- 알림은 기기 로컬 알림이 기본 경로다.
- 알림 권한이 없으면 예약하지 않는다.
- 일정별 알림 토글이 꺼져 있으면 예약하지 않는다.
- 종료일 이후 occurrence는 예약하지 않는다.
- 알림을 탭하면 홈으로 이동한다.
- 알림 제목은 사용자 기기에서 복호화한 일정 제목을 사용한다.
- 알림 본문에는 설명을 넣지 않고 예정 시각만 짧게 표시한다.

### 종료일 정책

- 종료일은 occurrence local date 기준으로 마지막 발생 날짜를 뜻한다.
- 반복 일정은 종료일을 선택적으로 가질 수 있고, 한 번 일정은 종료일을 갖지 않는다.
- 새 일정의 종료일은 시작일보다 빠를 수 없다.
- 수정 모드의 종료일은 수정하는 날보다 빠를 수 없다.
- 종료일 변경은 이후 occurrence에만 적용된다.
- 완료일 기준 일정에서도 종료일은 완료한 날짜가 아니라 occurrence local date 기준으로 적용된다.
- 기기 로컬 알림은 종료일 이후 occurrence를 예약하지 않는다.
- 종료일이 없는 기존 일정과 반복 일정은 종료일 없음 상태를 유지한다.

### Privacy

- 일정 제목과 설명은 서버 DB에 평문으로 저장하지 않는다.
- 제목과 설명은 사용자별 content key로 암호화한다.
- 새 기기나 앱 재설치 뒤에는 서버 측 내용 복구 흐름으로 content key를 복구할 수 있다.
- 서버 측 내용 복구는 content key만 다루며 일정 제목과 설명을 복호화하지 않는다.
- 복구 호출은 평문 내용이나 key 없이 내부 감사 이벤트로 남긴다.
- 계정 삭제는 사용자 계정, 일정, occurrence 처리 기록, 기기, content key 복구 데이터를 삭제 대상으로 본다.
- 계정 삭제는 임시 비활성화나 로그아웃으로 대체하지 않는다.
- 로그인된 사용자의 계정 삭제는 앱 안에서 즉시 처리한다.
- 계정 삭제 요청은 앱 밖 공개 웹 경로에서 접수한다.
- 계정 삭제 요청은 앱 삭제, 로그인 불가, 기기 접근 불가 상황을 위한 보조 경로다.
- 첫 출시의 계정 삭제 요청은 공개 Notion 안내 페이지와 운영 문의 이메일로 접수한다.
- 계정 삭제 요청은 가입에 사용한 Apple 또는 Google 계정 이메일로 보낸 요청만 처리 대상으로 본다.
- 계정 삭제 요청에는 앱 설정에 표시되는 계정 이메일을 함께 적도록 안내한다.
- 이용약관 전문은 앱 안에 복제하지 않고 공개 웹 페이지로 제공한다.
- 첫 출시 이용약관은 무료 개인 리마인더 앱 범위를 기준으로 한다.
- 유료 결제, 구독, 광고를 도입하기 전에는 이용약관과 개인정보처리방침을 개정한다.
- 개인정보처리방침 전문은 앱 안에 복제하지 않고 공개 웹 페이지로 제공한다.

### Multi-device

- 서버 데이터가 최종 기준이다.
- 변경 후에는 서버 데이터를 다시 조회한다.
- 같은 occurrence가 이미 다른 기기에서 처리된 경우 최신 상태를 다시 반영한다.
