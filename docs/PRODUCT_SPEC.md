# Product Spec

이 문서는 사용자가 관찰할 수 있는 제품 범위와 동작을 정의한다.
용어는 [`CONTEXT.md`](../CONTEXT.md), 계산 규칙은 [`DOMAIN_LOGIC.md`](DOMAIN_LOGIC.md), 구현 경계는 [`SYSTEM_DESIGN.md`](SYSTEM_DESIGN.md)를 따른다.

## 제품

Ttokttak은 복용, 교체, 정비, 학습처럼 예정 시점이 있는 생활 항목을 관리하는 개인 리마인더 앱이다.
사용자는 일정을 등록하고 알림을 받은 뒤 각 occurrence를 완료하거나 건너뛴 기록을 남긴다.

첫 스토어 출시는 대한민국을 기본 시장으로 한다.
앱, 공개 문서와 스토어 원문은 한국어와 English를 제공한다.
이용약관, 개인정보처리방침, 계정 삭제 요청과 지원 문서는 한 URL에서 두 언어를 제공한다.

## 범위

- Apple 또는 Google 로그인.
- 한 번 및 반복 일정 생성, 수정과 삭제.
- 알림, 종료일, 일정 색상과 지원되는 완료일 기준 계산 설정.
- 홈 피드에서 occurrence 확인, 완료와 건너뛰기.
- 일정 목록, 상세와 월간 캘린더.
- 기기 로컬 알림과 앱 아이콘 뱃지.
- iOS 홈 화면 위젯.
- 한국어와 English 표시 언어.
- 시스템, 라이트와 다크 테마.
- 표시 이름, 로그아웃과 계정 삭제.
- 로그인 계정의 일정 데이터 동기화.

현재 다음 기능은 제공하지 않는다.

- Android 홈 화면 위젯.
- 알림함과 원격 푸시.
- snooze와 반복 재알림.
- 통계.
- 일정 공유와 협업.
- 결제, 구독과 광고.
- 완전한 오프라인 충돌 해결 UX.

## 반복 방식

사용자는 한 번, 매일, n일마다, 매주, n주마다, 매달 또는 n달마다를 선택할 수 있다.

완료일 기준 계산은 매일, n일마다, 매달과 n달마다에서만 제공한다.
한 번 일정과 주간 일정은 고정형만 제공한다.

## 화면

### 내비게이션

- 홈, 목록, 캘린더와 설정을 하단 탭으로 제공한다.
- 일정 추가는 탭 목적지가 아닌 공통 동작으로 탭 루트에서 제공한다.
- 상세, 생성과 수정에서는 하단 탭과 일정 추가 동작을 숨긴다.
- 선택한 탭을 다시 눌러도 화면 위치나 탐색 상태를 바꾸지 않는다.

### 로그인

- Apple과 Google 로그인을 제공한다.
- 로그인 전에 이용약관과 개인정보처리방침을 확인할 수 있다.
- 세션이 준비되면 홈으로 이동한다.

### 홈

- 오늘부터 15일 범위의 날짜를 선택할 수 있다.
- 오늘에는 지난 일정, 오늘과 다가오는 일정 섹션을 보여준다.
- 지난 일정은 일정별 최신 occurrence 하나만 보여준다.
- 다가오는 일정은 오늘 이후 14일 범위다.
- 다른 날짜에는 해당 날짜의 예정 일정만 보여준다.
- 완료와 건너뛰기는 홈에서만 제공한다.
- 지난 일정을 처리하면 같은 일정에서 그보다 이전인 미해결 occurrence도 같은 동작으로 처리한다.

### iOS 홈 화면 위젯

- 작은 크기와 중간 크기의 읽기 전용 위젯을 제공한다.
- 일정별 최신 지난 일정 하나와 오늘의 미처리 occurrence 전체를 한 목록으로 보여준다.
- 지난 일정은 최신순, 오늘 occurrence는 알림 시각순으로 이어서 보여준다.
- 작은 위젯은 최대 3개, 중간 위젯은 최대 6개를 보여주고 숨긴 수를 표시한다.
- 각 항목은 일정 색상, 제목과 알림 시각을 보여주며 지난 일정에는 지난 날짜 수도 표시한다.
- 반복 규칙과 설명은 보여주지 않는다.
- 일정이 없는 상태와 로그인이 필요한 상태를 구분해 안내한다.
- 위젯을 누르면 홈으로 이동한다.
- 문구는 앱의 표시 언어를 따르고 색상은 시스템 테마를 따른다.
- 앱 실행, foreground 복귀, 일정 변경과 occurrence 처리 뒤에 갱신한다.
- 다른 기기의 변경은 현재 기기에서 앱을 다시 열기 전까지 반영되지 않을 수 있다.

### 일정 목록

- 활성 일정을 제목순 또는 생성순으로 보여준다.
- 각 행에는 제목, 반복 요약과 다음 예정 시각을 표시한다.
- 다음 occurrence가 없으면 예정 없음으로 표시한다.
- 행을 누르면 일정 상세로 이동한다.

### 일정 상세

- 진입한 occurrence, 최신 지난 일정 또는 다음 occurrence를 대표 상태로 보여준다.
- 설정 요약과 실제 처리 시각 기준 최근 처리 기록 5건을 보여준다.
- 예정 시각과 실제 처리 시각이 다르면 둘 다 표시한다.
- 완료와 건너뛰기는 제공하지 않는다.
- 수정과 일정 삭제를 제공한다.
- 복구 불가 일정은 안내와 일정 삭제만 제공한다.

### 일정 생성과 수정

- 제목은 필수이고 설명은 선택이다.
- 시작일, 알림 시간, 반복 방식, 일정 색상과 알림 사용 여부를 설정한다.
- 반복 일정에는 종료일을 추가하거나 제거할 수 있고 한 번 일정에는 종료일을 제공하지 않는다.
- 일정 색상은 7개 프리셋 또는 불투명 사용자 지정 색상으로 선택하며 기본값은 빨강이다.
- 사용자 지정 팔레트는 조작 시 즉시 적용하고 조작 없이 닫으면 기존 선택을 유지한다.
- 수정할 때 시작일은 바꿀 수 없다.
- 수정 화면에서도 일정 삭제를 제공한다.
- 규칙 변경은 이후 occurrence에만 적용한다.

### 캘린더

- 월간 달력과 선택 날짜의 occurrence 목록을 보여준다.
- 월을 바꾸면 해당 월의 1일을 선택한다.
- 날짜 marker는 occurrence 상태가 아니라 일정 색상을 사용한다.
- 선택 날짜 목록에는 시각, 상태와 제목을 표시한다.
- occurrence 처리 동작은 제공하지 않는다.

### 설정

- 알림 권한을 확인하고 시스템 설정으로 이동할 수 있다.
- 표시 언어, 테마와 현재 시간대를 보여준다.
- 표시 이름을 수정하고 계정 이메일을 확인할 수 있다.
- 표시 이름은 공백일 수 없고 최대 30자다.
- 이용약관, 개인정보처리방침과 앱 버전을 확인할 수 있다.
- 로그아웃과 계정 삭제를 제공한다.
- 계정 삭제는 삭제 범위와 비가역성을 확인한 뒤 실행한다.

## 제품 정책

### occurrence 처리

- 처리하지 않은 occurrence는 다음 날로 이동하지 않고 지난 일정으로 남는다.
- 하나의 occurrence는 한 번만 완료 또는 건너뛰기 처리할 수 있다.
- 상세와 캘린더는 확인용이며 occurrence 처리는 홈에서만 수행한다.

### 종료일

- 종료일은 반복 일정이 occurrence를 만드는 마지막 날짜이며 해당 날짜를 포함한다.
- 사용자는 생성 후에도 종료일을 추가, 변경 또는 제거할 수 있다.
- 종료일 변경은 과거 occurrence와 처리 기록을 바꾸지 않는다.
- 종료일이 지난 일정도 삭제하지 않았다면 목록과 상세에 남는다.

### 일정 삭제

- 일정 삭제는 상세와 수정에서 제공한다.
- 삭제한 일정은 홈, 목록, 캘린더와 기기 로컬 알림 대상에서 제외한다.
- 일정 삭제는 계정 삭제와 별개다.

### 알림

- 기기 로컬 알림을 기본 경로로 사용한다.
- 권한이 없거나 일정 알림이 꺼져 있으면 예약하지 않는다.
- 종료일 이후 occurrence와 복구 불가 일정은 예약하지 않는다.
- 알림을 누르면 홈으로 이동한다.
- 제목에는 일정 제목을 사용하고 본문에는 설명을 넣지 않는다.
- 앱 아이콘 뱃지는 일정 알림 사용 여부와 관계없이 처리 필요 수를 표시한다.
- 완료 또는 건너뛰기한 occurrence의 표시 알림은 제거한다.
- 로그아웃과 계정 삭제 때 표시 알림과 뱃지를 정리한다.
- Android 숫자 뱃지는 런처 지원 범위를 따른다.
- 기기 상태, OS 정책과 권한에 따라 알림이 늦거나 표시되지 않을 수 있다.

### 기기 설정

- 표시 언어와 테마는 현재 기기에만 저장하며 로그인 상태와 무관하게 적용한다.
- 표시 언어를 고르지 않으면 지원되는 기기 언어를 사용하고 그 외에는 한국어를 사용한다.
- 사용자가 입력한 제목, 설명과 표시 이름은 표시 언어가 바뀌어도 번역하지 않는다.
- 테마 기본값은 시스템이며 직접 고른 값이 기기 설정보다 우선한다.

### 개인정보와 계정

- 일정 제목과 설명은 서버 DB에 평문으로 저장하지 않는다.
- 사용자는 별도 복구 비밀번호 없이 새 기기에서 내용을 복구할 수 있다.
- 서버 DB만으로 제목과 설명을 복구할 수 없어야 하지만 서버 실행 경계는 신뢰하므로 strict E2EE는 아니다.
- 로그인한 사용자의 계정 삭제는 앱에서 즉시 처리한다.
- 계정 삭제는 사용자 계정, 일정, occurrence 처리 기록과 내용 복구 데이터를 대상으로 한다.
- 로그인할 수 없는 사용자는 공개 계정 삭제 요청 경로를 사용할 수 있다.
- 이용약관과 개인정보처리방침 전문은 공개 웹 문서로 제공한다.
